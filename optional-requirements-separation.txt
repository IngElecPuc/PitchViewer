# Dependencias para separación vocal/instrumental offline.

#     python tools/install_separation_dependencies.py
#
# Instalación directa mínima:
#     pip install -r optional-requirements-separation.txt
#
# Notas:
# - imageio-ffmpeg entrega un binario ffmpeg usable desde Python, útil para MP3.
# - Demucs es el motor estable recomendado.
# - PitchViewer ejecuta Demucs mediante un runner propio que lee WAV con soundfile
#   para evitar fallas de torchaudio/TorchCodec en Windows + Python reciente.
# - Audio Separator / UVR se intenta desde el instalador Python y no desde este
#   archivo, porque en Windows + Python 3.14 puede fallar por dependencias
#   nativas como diffq-fixed. Si falla, el instalador continúa y Demucs queda usable.

# Motor principal: Demucs / Hybrid Transformer Demucs.
demucs

# Carga/escritura de WAV y stems.
soundfile

# Binario ffmpeg empaquetado para Python. Permite exportar MP3 desde la app
# aunque ffmpeg.exe no esté instalado globalmente en PATH.
imageio-ffmpeg
